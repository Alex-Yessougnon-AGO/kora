# Delivery Checklist

## Avant le code
- [ ] Lire tous les documents.
- [ ] Inspecter dépôt, scripts, versions et statut Git.
- [ ] Vérifier documentation LibraryUI et choisir une variante.
- [ ] Vérifier le statut et les règles actuelles du challenge.

## Avant soumission
- [ ] Le projet s'installe depuis un clone.
- [ ] Build production réussie et tests exécutés.
- [ ] Vente, stock, paiement partiel et dépenses testés.
- [ ] Données persistées après rechargement.
- [ ] Responsive vérifié sur mobile, tablette et desktop.
- [ ] Aucun bouton principal inactif.
- [ ] Au moins quatre composants LibraryUI réels documentés.
- [ ] README complet, pas de secrets.
- [ ] Capture d'écran et démo vérifiée si possible.
- [ ] Lien dépôt et démo soumis via le formulaire officiel.

## Rapport final obligatoire
1. Fonctionnalités réellement implémentées.
2. Fichiers importants créés/modifiés.
3. Noms exacts et emplacements des composants LibraryUI.
4. Commandes build/tests exécutées et résultats.
5. Limites et problèmes restants.
6. URL de démo seulement si vérifiée.
7. Étapes manuelles restantes.
