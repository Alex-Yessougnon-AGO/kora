# Kora — Project Master Context

## Résumé
Kora est une interface web de gestion quotidienne destinée aux petits commerces : boutiques, vendeurs de vêtements, épiceries et commerces de proximité. Elle aide à suivre ventes, dépenses, stock, dettes et encaissements dans une interface simple, rapide et adaptée au mobile.

## Problème
Les commerçants peuvent gérer leurs opérations avec carnets, calculs manuels et plusieurs outils. Ils ont besoin de savoir ce qui a été vendu, ce qui a été encaissé, ce qui reste dû, les dépenses, le bénéfice estimé et les produits à réapprovisionner.

## Proposition de valeur
Kora ne doit pas être un dashboard décoratif. Les actions doivent mettre à jour les chiffres concernés : une vente modifie l'historique, les encaissements, le stock et les indicateurs. Une dépense met à jour les rapports. Un paiement partiel conserve le solde exact.

## Public et contexte
- Propriétaire ou employé d'un petit commerce.
- Priorité aux commerces francophones d'Afrique de l'Ouest.
- Interface en français, montants de démonstration en FCFA/XOF.
- Ordinateur, tablette et smartphone.
- Expérience compréhensible sans formation.

## Limites
Kora Challenge Edition est un prototype front-end, pas un logiciel comptable certifié ni une application bancaire. Les données sont fictives. Ne pas prétendre à une connexion réelle à MTN MoMo, une banque ou un fournisseur de paiement.

## Différenciateurs
1. Saisie rapide.
2. Distinction entre chiffre d'affaires, encaissements, coût des marchandises, dépenses et bénéfice estimé.
3. Stock et rapports cohérents après les opérations.
4. Expérience mobile soignée.
5. États vides, erreurs, confirmations et données de démonstration réalistes.
6. Architecture préparée à une future API, sans simuler une synchronisation multi-appareils.

## Exigences du challenge
Le brief utilisateur indique : création originale en Angular, au moins quatre composants LibraryUI, responsive mobile/tablette/ordinateur, code source fourni et démo si possible. La capture montre les catégories Data, Actions, Forms, Overlay, Layout, Autres, Feedback, Media et Navigation, et les variantes Angular × Bootstrap et Angular × Tailwind. Vérifier la documentation réelle avant le choix final.

## Objectif
Livrer une application Angular installable, exécutable, responsive et déployable, utilisant au moins quatre composants LibraryUI authentiques, clairement identifiés dans le README.
